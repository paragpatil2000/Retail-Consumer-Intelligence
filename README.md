# Retail Consumer Intelligence Platform

## Overview

Retail Consumer Intelligence Platform is an end-to-end Data Science project inspired by real-world retail analytics and market research workflows.

The project focuses on consumer behavior analysis, sales forecasting, market basket analysis, customer segmentation, promotion effectiveness, and interactive dashboards.

## Tech Stack

- Python
- SQL
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- FastAPI
- Power BI
- Docker

## Modules

- Data Generation
- Data Preprocessing
- Feature Engineering
- Sales Forecasting
- Market Basket Analysis
- Customer Segmentation
- Promotion Effectiveness
- Dashboard
- API
